Configure how it looks

In the Marquee Editor you can set the position of the song elements to your preferences. There are included presets for most common stream setups. This plugin is ideal for streamers who want to display the current song information on their stream.

OBS Browser Source URL

To use Marquee, add a Browser Source in OBS. Use the URL below. In OBS Browser Source for Marquee set the Width/Height to match the Width/Height you set in the Marquee editor. This will give you a perfect 1 to 1 marquee image in OBS.
